Tentang Proyek

Ringkasan data, metode, dan batasan sistem.

📦 Dataset

IBM HR Analytics Employee Attrition (Kaggle) berisi {{ m.n_rows }} karyawan. Variabel target: Attrition (Yes = resign, No = bertahan). Data dibagi {{ m.n_train }} latih dan {{ m.n_test }} uji dengan pembagian stratified.

🧹 Pra-pemrosesan

Pengecekan missing values (median untuk numerik, modus untuk kategorikal), lalu fitur kategorikal (OverTime, MaritalStatus, BusinessTravel) diubah dengan One-Hot Encoding menjadi {{ m.n_features }} fitur.

🌳 Model

Model A tumbuh bebas untuk menunjukkan overfitting. Model B di-pruning dengan pengaturan hiperparameter dan dipakai pada aplikasi ini, disimpan dengan Joblib.

⚠️ Batasan

Dataset bersifat fiktif dan kelasnya tidak seimbang, jadi sebagian karyawan yang resign tidak terdeteksi. Gunakan hasil sebagai pendukung diskusi, bukan dasar tunggal keputusan terkait karyawan.
